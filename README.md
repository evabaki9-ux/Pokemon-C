# repo-1 — MONTERRA: Legends of the Veldt

An original monster-collecting RPG in the spirit of the GBA classics, written
in **C (C11) + SDL2**, compiling to both a **native binary** and
**WebAssembly** (playable in the browser).

> All content is original: creatures, names, moves, maps, and characters are
> this project's own. No Pokémon/Game Freak assets, names, or data are used.
> Mechanics are "inspired by" the genre, implemented from scratch.

## Play (browser)

`make wasm` then serve `web/` (`make serve`), open in a browser.
Requires [Emscripten](https://emscripten.org) (`emsdk`).

**Controls:** Z/Enter = confirm · X = cancel · WASD/arrows = move · M = menu

## Play (native)

```
sudo apt install libsdl2-dev build-essential
make native && ./bin/monterra
```

## What's in the game (v1)

- **Overworld:** 5 maps (your house, Prof. Maple's lab, the Care Station,
  Verdan Town, Route 1), smooth tile-based movement, animated water/grass/
  flowers, ledges you can hop down, warps with door fades, signs, NPCs.
- **Battles:** turn-based, speed/priority ordering, 24 moves, 8-type chart,
  STAB, crits, burn/paralysis/sleep, stat stages, HP-drain animation,
  catching with the Gen-3 shake formula, XP, level-ups, move learning,
  evolution, and a trainer battle (Camper Liam).
- **Systems:** party of 6, bag (potions/orbs), money, Pokédex-style
  seen/caught tracking, healing via Mom/the nurse, whiteout handling.
- **Engine:** pure-logic core (unit-tested headlessly, no SDL), data-driven
  tables for moves/species/items/maps, asset pipeline in Python/PIL.

## Asset pipeline

- `tools/gen_tiles.py` — 30 procedurally drawn 16px tiles (+ battle
  platforms, title background)
- `tools/gen_chars.py` — 16px walking sprites (4 directions, palette swaps)
- `tools/bake_font.py` — pixel font atlas from **Press Start 2P**
  ([SIL OFL](https://github.com/google/fonts/blob/main/ofl/pressstart2p/OFL.txt),
  © CodeMan38)
- `tools/process_art.py` — chroma-keys AI-generated creature art into
  64x64 battle sprites
- `tools/gen_maps.py` — validates ASCII maps (warps, NPC placement,
  rectangularity) and emits `src/data/maps.c`

Regenerate everything with `make assets`.
